## What was optimized

### 1. Debounced `ActionManager` saves (fixes slow mode toggling)

**Before:** Every single `set()` or item in `set_many()` wrote the full compacted JSON to disk. The `_compact()` algorithm is O(n²) because it iteratively collapses parent folders.

**After:** Saves are batched — 500ms of silence must pass before a single write occurs. Rapid mode-cycling generates only 1 disk write instead of N. The `_compact()` algorithm now has an early exit path for small datasets (≤20 entries) and a hard cap of 100 iterations.

### 2. Coalesced text refresh (fixes "unselect 1 file, text empty takes seconds")

**Before:** Every click to cycle a mode called `_refresh_text()` immediately, which: walked all selected files, read each from disk, normalized content, extracted signatures, generated the tree, and deduplicated. Even clearing the last file triggered the full pipeline.

**After:** 
- Refreshes are coalesced via `after_idle()` — only 1 refresh per idle cycle regardless of how many clicks happen.
- `_selected_files()` result is cached and invalidated only when modes change.
- **Empty selection → returns instantly.** The "unselect last file" case now takes ~0ms.

### 3. Background thread + Cancel button (fixes "Open all freezes app")

**Before:** `set_action_all()` ran `os.walk()` + `set_many()` synchronously on the main/GUI thread, freezing the UI completely.

**After:** The file-tree walk runs in a daemon thread. A "✕ Cancel" button appears after 300ms. Clicking it signals a `CancellationToken` — the walker checks it every 500 files and exits cleanly. The GUI stays responsive throughout.

### 4. Performance logging (new: see what's slow)

A `PerfCollector` singleton tracks every instrumented operation. Operations slower than `PERF_LOG_THRESHOLD_MS` (50ms default) are printed to stderr. Click the new **📊 Perf Report** button for an aggregate breakdown:

```
======================================================================
 PERFORMANCE REPORT
======================================================================
  action_mgr.save                n=  42  avg=   45.3ms  max=  189.0ms
  gui.refresh_text               n=  23  avg=  120.1ms  max=  450.2ms
  gui.load_tree                  n=   1  avg=   15.2ms  max=   15.2ms
======================================================================
```

### 5. New settings at the top of the file

```python
PERF_LOG_ENABLED = True        # Master switch
PERF_LOG_THRESHOLD_MS = 50     # Only log ops slower than this
PERF_LOG_TO_FILE = False       # Also write perf_log.jsonl
CANCEL_TIMEOUT_MS = 300        # Show cancel button after this many ms
```

### 6. Graceful shutdown

Closing the window calls `_on_close()` which cancels any running background operation, flushes pending saves to disk immediately, then destroys the window. No data loss.
