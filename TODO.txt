Implemented: a small JSON registry in the OS temp dir tracks dir -> {port, pid}
for live servers. Same dir (or a sub-folder of an already-served dir) reuses the
running server (no new process); a different dir always gets a fresh
OS-assigned free port, so a forgotten server from another terminal is left
running untouched. Dead entries (closed terminal / crashed process) are
detected via port+pid liveness checks and dropped automatically. No extra
dependencies - stdlib http.server/socketserver only. Also works when the
clipboard/arg points at a folder.
